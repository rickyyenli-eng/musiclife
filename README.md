# 回音 ECHO — 音樂人生模擬器

十六歲的第一次開口，到最後一場安可。五種職業、可以中途轉行、十五種結局。

**線上遊玩：** https://rickyyenli-eng.github.io/musiclife/

---

## 這是什麼

一款種子化的音樂人生模擬器。畫面上會有很多數字，但沒有一個數字是真的——你看到的「唱功／品味／筆力」全是**自我評估值**，真實數值整局隱藏，只在引退時才揭曉。

五個心理學機制不是裝飾，是核心規則：

| 機制 | 在遊戲裡長什麼樣 |
|---|---|
| 不可靠的自我認知 | HUD 第二格是自評，不是實力。聲量漲會讓自評跟著膨脹 |
| 歸因風格（Seligman） | 每次失敗後選擇怎麼解釋，決定復原速度與判斷準確度 |
| 白熊效應（Wegner） | 「告訴自己不要出錯」永遠是壞選項，而且會累積 |
| 峰終定律（Kahneman） | 結局給兩份文件：記錄簿（真實數字）與回憶錄（只由最高峰＋最後一件事生成） |
| 社會比較 | 同期對手的數字每四年跳出來一次，可以選擇永久停止追蹤 |

## 五種職業

每個職業盯著的數字不一樣，會燒掉的東西也不一樣。

| 職業 | 你盯著的數字 | 你會燒掉的 |
|---|---|---|
| 歌手 | 聲量 | 嗓子 |
| 製作人 | 掛名 | 耳朵 |
| 詞曲作者 | 被唱幾次 | 存量 |
| 樂手 | 通告 | 手 |
| 音樂老師 | 口碑 | 熱情 |

天賦選項會跟著職業換（歌手看聲線、製作人看耳朵、樂手看手），但吃的是同一套倍率：

| 原型 | 作用 |
|---|---|
| 精準 | 成長 ×1.18，自評擺盪 ×0.72 —— 學得快，但永遠低估自己 |
| 外放 | 聲量 ×1.30，自評擺盪 ×1.45 —— 數字漲得快，自我感覺也是 |
| 特色 | 成長 ×1.22，磨損 ×1.55 —— 辨識度高，但耗得快 |
| 耐操 | 磨損 ×0.55，白熊 ×0.50 —— 撐得久、不太抖，但沒有突出的地方 |

27 歲與 33 歲各有一次轉行機會。最終職業與數值分層決定你拿到哪一種結局。

## 種子

相同種子＋相同選擇＝相同人生。網址可以帶種子分享給朋友：

```
https://rickyyenli-eng.github.io/musiclife/?seed=abc12345
```

結局頁有「複製連結給朋友」。同一顆種子，數據會一樣，回憶錄不會。

## 技術

單一 HTML 檔，無框架、無建置流程、無外部相依（字型走 Google Fonts CDN）。直接開檔案就能玩。

- 亂數：seeded mulberry32，確保同種子可重現
- 事件池：40 個，一輪約用掉 24 個
- 不使用 localStorage 或任何後端，不蒐集任何資料
